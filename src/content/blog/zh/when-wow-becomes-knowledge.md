有一次，在一段很普通的 AI 对话里，突然弹出一张图。

不是「请按品牌规范出一张 Hero」。我甚至没有说 ThinkNote、没有说官网、没有说 Copy → Note → DOCX。就是聊着聊着，屏幕上出现了这张图。我停了两秒，第一句话几乎是本能：

> 太帅了。

如果只存图、点个赞、换下一个话题，这次认知事件就结束了。一张漂亮图进了相册，脑子里什么都没留下。

可「哇」本身是信号。它在说：你原来以为世界是这样的，刚才那一下，边界被撞开了一条缝。

后来我把聊天往回翻，才发现更值得写下来的，不是这张图有多好看，而是**它几乎是「随手」来的**。真正的起点，比出图早一步。

## 事情的真正起点，不是这张图

再往前一点，我问的是一件很技术、也很具体的事：

> 现在 APNG 如何了，就是能动的 PNG。

我想知道的是格式：会动的 PNG 现在能不能用、比 GIF 好在哪、适不适合做产品演示。它讲了一通支持情况、透明、真彩色，然后落到 ThinkNote 上——如果你要的是 2～5 秒、循环、按钮亮起、鼠标点一下、UI 发生变化，APNG 会比 GIF 漂亮很多；如果是十几秒的完整录屏，那还是视频。

聊完，我随口说了一句：

> 那你随意帮我生成 1 张，我看看效果。

然后那张 Copy → Note → DOCX 就来了。

所以这不是「我要一张帅图」的成功案例。是一次关于「产品该怎么动」的闲聊，后面跟着一句几乎没有要求的「看看效果」。惊喜发生在这句话之后，但营养积在这句话之前。

这一点本身，就已经在改我对 AI 的用法。

我原先默认：好输出来自好提示词。写得越精确，结果越可控。这次相反——**精确的提问在前面，随意的一笔在后面。** 前面把上下文装满了：APNG、要动态、要彩色、要吸引人、ThinkNote 是 Chrome 插件、演示该是短循环而不是长视频。后面那句「随意」，其实一点都不空。它是在一块已经湿润的土上，随手按了一下。

空白对话框里说「随意生成一张」，多半得到一张漂亮的空壳。一段已经有方向的对话里说「随意」，才容易冒出你没要、但正好打在你关心之处的东西。

## 惊艳是信号，不是终点

我原先对「AI 画图」的模型很粗：给个产品名，它画一张好看的图。好看就好看，到此为止。

但这张图让模型失效了。它不是在画 Logo，而是在两秒内讲完一个故事：左边是 ChatGPT 里的公式、表格、代码；中间是 ThinkNote 插件；右边变成可编辑的 DOCX。眼睛会跟着黄箭头走。中间那一小块弹出层，一秒钟回答「这东西到底能干什么」。

也就是说，我以为自己在看一张图，其实撞上了一套我还叫不出名字的东西：产品叙事、视觉动线、颜色层级、按动画来构图、甚至快要成形的品牌语言。

聊天里偶尔会遇到这种高光。一段突然说透的话、一个你没想到的类比、一张让人停下来的图。它们不是每天都有。遇到了，值得停下来深挖——否则你只是消费了一次惊喜，没有更新自己的认知。

之前写过 [如何用 AI 升级你的大脑](/zh/blog/upgrade-your-brain-with-ai)：完整循环是 Chat → Think → Note → Share。这篇只切其中最容易错过的一刻：**输出突然让你「哇」了一声之后，怎么把这一声变成能带走的知识。**

## 往回挖，也往前挖

我当时追问的是这一句：

> 你是如何创作出这张图的，你思考了哪些？它实在太帅了。

这是入口，不是全部。同一种「哇」，至少还能往几层挖。有的往前，有的其实要往回。

**往回看它从哪来。** 惊喜很少凭空出现。这张图前面是 APNG，再前面是「要动态、彩色、吸引人」。把镜头拉远，你才会看见：哇的不是一次抽卡，是上下文终于够厚，随手一按就出芽了。以后再遇到高光，先翻几条记录：它是接在哪个真正的问题后面的？

**追问过程。** 别停在「真好看」。问它怎么做出来的、先想了什么、故意没做什么。过程比成品值钱：成品你会忘，过程能迁移。

**给它命名。** 视觉故事、视觉动线、颜色层级、动画关键帧、品牌语言——没有名字的东西进不了长期记忆。你叫得出名字，下次才能主动用。

**对照差异。** 为什么不是「巨大 Logo + 一句 slogan + 一张截图」？如果做成 Apple / Linear 那种极简企业风，会漂亮，但还会不会让人停下来？对照一次，你才知道「帅」到底帅在哪，而不是笼统觉得「AI 画得好」。

**请它迁移。** 这套语言能不能用到官网、下一张功能图、一段会动的 PNG？惊喜如果只能用一次，就还只是运气。

**请它教你会做。** 下次我自己出图，应该先想哪三件事？目标不是永远靠它生成，而是把「会看」变成「会做」。

**跨域映射。** 图的动线，很像文章的叙事线：读者的眼睛也要有一条路可走。颜色层级很像信息优先级：不是每句话都同等重要。按动画关键帧来构图，很像做产品演示：先想哪几下必须动，再倒推静态画面。跨过这一步，一张图就开始改你写字、做产品、讲课的方式。

**写成笔记，并分享出去。** 「哇」极容易蒸发。窗口一关，只剩模糊的赞叹。写下来，才是你的；拿给别人看，才会被现实摩擦、修正。这篇本身，就是这一步。

不是每次都要全做。选一种入口进去即可。我选的是最轻的一种：追问过程。但把聊天完整翻开之后，我发现**往回看**几乎同样重要。没有这一步，我会把这次写成「AI 真会画图」；有了这一步，才写成「一次技术闲聊，如何长出一张产品图」。

## 追问一句之后，我拿走了什么

它没有说「我用了某某模型和某某提示词」。它说的是一套设计判断。我把它改写成自己能用的几条——不是聊天记录，是认知增量。

![Copy → Note → DOCX：把 AI 对话里的东西变成可编辑文档](/images/uploads/copy-note-docx.png)

**先有故事，再有画面。** 没有先画 Logo，而是把 ThinkNote 的核心动作变成一条线：ChatGPT → ThinkNote → DOCX。画面因此天然有方向。单独放一张插件截图，冲击力弱得多。

这改的是我的默认顺序。以前想的是「画什么」，现在会先问：**用户两秒内要看懂什么故事？** 官网、功能页、甚至一篇文章的开头，都可以用同一问。没有故事的图，再精致也只是装饰。

**先按会动的东西来构图。** 这里接上了前面的 APNG。它脑子里想的不是海报，而是：如果以后做成会动的 PNG，哪些该动？黄箭头移动、星星闪、鼠标点、Chrome 轻跳、Export 有反馈、Copy → Note → DOCX 逐个出现、底部三个 badge 依次亮起。所以这张静态图其实是一帧动画的关键帧。

我以前把「动」理解成后期特效：先有一张静的，再找人加箭头、加点击。现在知道，动可以是构图时就埋进去的意图。**先问什么必须动，再决定画面上放什么。** 这不只适用于出图。做产品演示、做 landing page、写一段操作说明，都可以先列「哪几下是动作」，再填静止的部分。

**眼睛要有一条路。** 最重要的不是颜色，是人的眼睛怎么走：左上 → 左下 → 中间 → 右上 → 右下，也就是 Copy → Note → DOCX。即使不读字，也能读出「把 AI 里的东西变成文档」。

写文章、做页面、做演示，都可以先画这条路。读者不是在「看完整张图」，是在被你牵着走。路清楚，信息再多也不乱；路没有，再干净也让人不知道先看哪。

**中间只回答一个问题。** ThinkNote 放在正中，不是 Logo，而是一块很像 Chrome 插件弹出层的界面：公式、表格、代码、图片，然后一键导出 DOCX。用户心里那句「所以它到底能干什么」，一秒钟有答案。

产品解释可以很短，短到只占画面中心那一块。我以前总想把功能说全。现在更愿意问：如果只准回答一个问题，那一个是什么？其余的，交给第二眼、第三眼。

**颜色要有层级，不能平均撒。** 主体是白 + 蓝，黄用来当注意力和动作。蓝是产品，白是文档和干净，黄是能量，绿是成功，紫粉只做点缀。于是出现很清楚的蓝 + 黄 + 白，而不是「颜色很多所以丰富」。

丰富来自层级，不是来自调色盘。这也可以映射到文字：标题、论据、一句金句、一处强调，各有各的「颜色」。全是重点，就等于没有重点。

**第二层信息，让人看三眼。** 它刻意避开传统 SaaS Hero——巨大 Logo、一句 slogan、一张截图。塞进去的是 ChatGPT、公式、表格、Python、DOCX、鼠标、箭头、手写字、badge。

第一眼：哇，好丰富。  
第二眼：原来是 AI → Note → DOCX。  
第三眼：连公式、表格、代码都能留下。

三眼结构可以搬到写作里：先抓住，再讲清，再让人发现你没说完的那一层。一篇只让人看一眼的文章，多半是把第二层删掉了，或者第一层就没抓住。

**故意不那么严肃。** 全做成 Apple / Linear / 企业 SaaS，可能更「漂亮」，但不一定更吸引人。ThinkNote 偏 AI、插件、效率工具，所以它加了手绘、星星、黄线、爱心、鼠标点击——让它有一点玩具感、新鲜感、生命力。

我以前把「专业」理解成「收干净」。现在知道，有生命力也可以是一种专业判断。干净是一种选择，热闹也是一种选择。要先认产品是什么，再决定收还是放。ThinkNote 若收成医院说明书，正确，但不叫人。

**真正帅的，不是画工。** 是它开始形成一句产品视觉语言：ThinkNote = 把 AI 对话里的好东西抓出来，变成真正可以留下来的东西。往下走，官网、GIF、功能图都可以统一成：蓝色产品主体 + 黄色动作线 + 白色纸张 + 彩色小元素 + 手绘强调。用户以后看到某张动图，即使没看到 Logo，也会慢慢觉得：哦，这就是 ThinkNote 的东西。

从「做一张漂亮图」，跨进「品牌视觉系统」——这一步，才是那次「哇」真正值钱的地方。画工会过时，语言可以反复用。

## 藏在图后面的那条线：会动的 PNG

如果只复盘构图，会漏掉这件事的另一半。这张图会是现在这样，是因为再前面我问过 APNG。

它当时把格式问题翻译成了产品问题。GIF 能用，但 256 色、透明难看，做 UI 动效经常发糊。APNG 保留 PNG 的透明和真彩色，主流浏览器都能当普通图片播，不需要再套一层播放器。代价是：它仍然是「图片动画」，不是视频。十几秒、连续画面、高帧率，文件会迅速变沉，那是 WebM / MP4 的地盘。

于是有一条很清楚的尺子：

> 2～5 秒、循环、按钮、鼠标、几十帧、要透明 —— 用 APNG（或 Animated WebP）。  
> 10 秒以上的完整屏幕录制 —— 用视频。  
> 先让人看懂故事的那一帧 —— 用静态 PNG。

我问的是「APNG 现在怎样了」。带走的却是：**ThinkNote 的演示不该默认做成 GIF，也不该默认做成一段很长的录屏。** 短循环的操作、带透明的 UI、能嵌进网页的小动画，才是这张图暗示的下一步。

它甚至把顺序说死了：静态 PNG → APNG → WebP → MP4，按场景选，而不是一股脑全用 GIF。这张图卡在第一级：它是关键帧。箭头、鼠标、星星、按钮、Copy → Note → DOCX，都是为第二级准备的。真做成会动的 PNG，不是把整张图拿去「变成 GIF」，而是让那些本来就该动的东西，逐层动起来。

所以技术闲聊和视觉惊艳，其实是同一条线。前面问「能动的 PNG 怎样了」，后面才会有一张**按会动来想的静图**。若我一上来就要封面，大概得到的是一张更像海报、更不像关键帧的东西。

这也是往回挖的收获：你以为在学一个文件格式，其实在学产品该以什么样的节奏被看见。

## 「随意」并不空

把两步放在一起，方法就清楚了。

先用一个**你真正关心的问题**把土壤浇湿。格式、用户、演示、品牌、卡点——越具体越好。不必一次问完，聊着聊着，上下文会自己变厚。

然后再留一只手给意外。一句「看看效果」「你随意」「如果这是官网第一眼」。要求越松，模型越会去用已经堆在对话里的东西。惊喜常常出在这里。

最后，当「哇」出现，不要只赞叹。往回问它接在哪；往前问它还没做完的是什么。对我来说，没做完的很明确：这张静图，本来就在等一帧一帧动起来。

这和另一篇里写的也很近：[不确定性，是人生的享受之一](/zh/blog/uncertainty-as-enjoyment)。意外带动情绪，「哇」就是那一下振幅；追问过程、给它命名、写成笔记，是把不确定收成一点点确定。没有前面，思考空洞；没有后面，体验只是一阵风。

AI 聊天特别容易停在风里。窗口不断刷出新的漂亮。你若只负责被打动，认知边界纹丝不动。

## 惊喜接回那条闭环

回头看，整件事并不短，只是当时发生得很快：

```
关心一个真问题（APNG / 产品该怎么动）
    → 上下文变厚
    → 一句「随意，看看效果」
    → 「哇」（信号：原有模型不够用了）
    → 往回看它从哪来，往前追问过程、命名、对照、迁移
    → 写成这篇
    → 下次：先浇土，再留意外；出图先想故事和动线；演示先想哪几下必须动
```

意外输出，是 Chat 里的高光。往回翻、追问、命名，是 Think。落成这篇，是 Note，也是 Share。

AI 不会自动扩展你的边界。它只会偶尔把边界撞开一条缝——有时缝就藏在一句「随意帮我看看」后面。缝出现的时候，别急着划走。先问一句：

**它到底在教我什么，是我以前不会的东西？**
