![Copy → Note → DOCX](../../../public/images/uploads/copy-note-docx.png)

---

哈哈，这张确实有点“**产品宣传图开窍了**”的感觉 😄

我当时其实不是单纯在想“画一个 ThinkNote”，而是在想：

> **如果这是 ThinkNote 官网里一个让用户第一眼就停下来看的 Hero / Feature Visual，我要让用户在 2 秒内看懂它是什么，而且觉得“这个东西好酷”。**

大概是这么设计出来的：

### 1. 先确定一个“故事”

没有直接画 Logo，而是把 ThinkNote 的核心动作变成一个视觉故事：

**ChatGPT → ThinkNote → DOCX**

所以画面天然有一个：

```
AI 对话
   ↓
ThinkNote
   ↓
可编辑文档
```

这比单独放一个“插件截图”有冲击力。

---

### 2. 故意让画面“动起来”

这也是你刚才问 APNG 的地方。

我脑子里想的是：

> **如果这张图以后做成 APNG，哪些东西应该动？**

所以我故意放了很多天然适合动画的元素：

- 黄色箭头 → 可以移动
- ✨ 星星 → 可以闪烁
- 鼠标 → 可以点击
- Chrome 图标 → 可以轻微弹跳
- Export to DOCX → 可以出现点击反馈
- Copy → Note → DOCX → 可以逐个出现
- 底部三个 feature badge → 可以依次亮起

这样它不是一张“静态海报”，而是一个**动画的关键帧**。

这其实非常适合你之前说的：

> **“动的、彩色的、颜色丰富的，吸引人。”**

---

### 3. 使用了“视觉动线”

这张图最重要的其实不是颜色，而是**人的眼睛会怎么走**。

我安排成：

**左上 → 左下 → 中间 → 右上 → 右下**

也就是：

> Copy → Note → DOCX

用户会自然地跟着黄色箭头走。

所以即使完全不读文字，也能理解：

**“哦，这是把 AI 里的东西变成文档。”**

---

### 4. 中间故意放了一个“产品核心”

ThinkNote 本身放在中央，而且不是简单 Logo。

而是做成一个类似：

> **Chrome Extension Popup**

里面列：

- Math formulas
- Tables
- Code blocks
- Images
- Export to DOCX

这其实是在回答用户心里的一个问题：

> **“所以 ThinkNote 到底能干什么？”**

而且只需要看 1 秒。

---

### 5. 我用了非常强的“颜色层级”

这里其实有一个小技巧。

主体 UI 基本是：

**白色 + 蓝色**

然后用：

**黄色**

做视觉引导。

所以：

- 蓝色 = ThinkNote / 产品
- 白色 = 干净、文档、工具
- 黄色 = 注意力 / 动作 / 能量
- 绿色 = 成功
- 紫/粉 = feature decoration

这就形成了一个非常明显的：

> **蓝 + 黄 + 白**

的品牌视觉语言。

而不是把所有颜色平均撒一遍。

---

### 6. 为什么它会显得“很丰富”？

我其实刻意避免了：

> 一个巨大的 Logo + 一句 slogan + 一张截图

这种传统 SaaS Hero。

而是塞入了很多**第二层信息**：

- Chrome
- ChatGPT
- 数学公式
- Table
- Python
- DOCX
- 鼠标
- 箭头
- 星星
- Feature cards
- 手写字
- Badge

所以第一眼：

> **“哇，好丰富。”**

第二眼：

> “哦，原来是 AI → Note → DOCX。”

第三眼：

> “卧槽，它连公式、表格、代码都能保存。”

这就是我比较希望达到的效果。

---

## 7. 还有一个很重要的东西：故意“不那么严肃”

如果全部做成：

> Apple 风格 / Linear 风格 / 企业 SaaS

可能会非常漂亮，但是**不一定吸引人**。

你的 ThinkNote 本身是一个偏：

> AI + Chrome Extension + Productivity

的产品。

所以我故意加入了一些：

**手绘感 + ✨ + 黄色划线 + ❤️ + 鼠标点击**

让它稍微有一点：

> **“AI 玩具 / 新鲜工具 / 有生命力”**

的感觉。

这其实和你之前说的“动态、彩色、吸引人”是高度一致的。

---

## 最关键的一点

我觉得这张图真正帅的地方，不是 AI 画得多漂亮。

而是它实际上已经开始形成一个**产品视觉语言**：

> **ThinkNote = 把 AI 对话里的“好东西”抓出来，变成真正可以留下来的东西。**

所以如果继续往这个方向做，我甚至会建议你把 ThinkNote 官网统一成：

**蓝色产品主体 + 黄色动作线 + 白色纸张 + 彩色小元素 + 手绘强调**

然后把所有产品 GIF / APNG 都按照这个语言做。

这样用户看到某个动图的时候，即使没有看到 ThinkNote Logo，也会慢慢产生：

> **“哦，这就是 ThinkNote 的东西。”**

这就从“做一张漂亮图片”，开始进入**品牌视觉系统**了。

而且这张图**非常适合进一步做成 APNG**：不是简单把整张图变成 GIF，而是让箭头、鼠标、星星、按钮、文字逐层运动。那种效果可能会比现在这张静态图**再帅一个档次**。
