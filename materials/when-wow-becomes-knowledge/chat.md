## 1. APNG 是什么、现在怎样

用户问：现在 apng 如何了，就是能动的 png。

要点：

- APNG = 会动的 PNG，类似 GIF，但保留 PNG 的透明、真彩色、无损。
- Chrome / Edge / Firefox / Safari 都已支持，可当普通 `<img>` 播放，不需要 JS。
- 适合 ThinkNote 这种：2～5 秒、循环、UI 操作、几十帧、透明背景。
- 10 秒以上完整录屏、30/60fps、几 MB 到几十 MB，更适合 WebM / MP4。
- 产品宣传不必一股脑用 GIF，可按场景：静态 PNG → APNG → WebP → MP4。
